## 📌 Deskripsi Aplikasi

Java Calculator merupakan aplikasi kalkulator berbasis desktop yang dikembangkan menggunakan bahasa pemrograman Java dan library Java Swing untuk membangun antarmuka grafis atau Graphical User Interface (GUI).

Aplikasi ini dirancang untuk membantu pengguna melakukan perhitungan aritmetika dasar dengan tampilan yang sederhana dan mudah digunakan. Aplikasi juga menyediakan fitur riwayat perhitungan agar pengguna dapat melihat kembali hasil operasi yang telah dilakukan.

Proyek ini dikembangkan sebagai bagian dari praktikum Informatika untuk menerapkan konsep pemrograman Java dalam pembuatan aplikasi desktop.

## ✨ Fitur Aplikasi

* ➕ Penjumlahan.
* ➖ Pengurangan.
* ✖️ Perkalian.
* ➗ Pembagian.
* 🔢 Perhitungan bilangan desimal.
* ⌫ Menghapus karakter terakhir menggunakan Backspace.
* 🔄 Mengubah tanda bilangan menggunakan tombol `+/-`.
* 🧹 Menghapus perhitungan menggunakan tombol `C`.
* 📜 Melihat riwayat perhitungan melalui tombol `HISTORY`.
* 🗑️ Menghapus riwayat perhitungan.
* 🎨 Antarmuka grafis dengan kombinasi warna maroon dan cream.
* ⚠️ Menangani input yang tidak valid dan pembagian dengan nol.

## 🚀 Cara Menjalankan Aplikasi

### Persyaratan

Pastikan perangkat sudah memiliki:

* Java Development Kit (JDK).
* Java compiler (`javac`).
* Terminal atau IDE seperti Visual Studio Code.

### Langkah 1 — Clone Repository

Buka terminal, kemudian jalankan:

```bash
git clone https://github.com/kaylaadila/Calculator-Project-by-KLP-4.git
```

### Langkah 2 — Masuk ke Folder Proyek

```bash
cd Calculator-Project-by-KLP-4
```

### Langkah 3 — Compile Program

Jika nama file dan class utama masih `KalkulatorKLP4.java`, jalankan:

```bash
javac KalkulatorKLP4.java
```

### Langkah 4 — Jalankan Aplikasi

```bash
java KalkulatorKLP4
```

Setelah berhasil dijalankan, jendela aplikasi kalkulator akan muncul dan siap digunakan.

**Catatan:** Perintah di atas mengasumsikan source code utama bernama `KalkulatorKLP4.java`. Jika nama file di repository berbeda, sesuaikan perintah compile dan nama class yang dijalankan.

## 🧪 Contoh Input dan Output

Berikut beberapa contoh operasi aritmetika yang dapat dilakukan menggunakan aplikasi.

| No. | Input            |    Operasi   | Output |
| :-: | ---------------- | :----------: | -----: |
|  1  | `12` dan `3`     |   `12 + 3`   |   `15` |
|  2  | `12` dan `3`     |   `12 - 3`   |    `9` |
|  3  | `12` dan `3`     |   `12 × 3`   |   `36` |
|  4  | `12` dan `3`     |   `12 ÷ 3`   |    `4` |
|  5  | `2.5` dan `3.25` | `2.5 + 3.25` | `5.75` |

### Contoh Penggunaan

Misalnya, pengguna ingin menghitung `12 + 3`.

1. Klik tombol angka `1` dan `2`.
2. Klik tombol `+`.
3. Klik tombol angka `3`.
4. Klik tombol `=`.
5. Hasil perhitungan `15` akan ditampilkan pada layar kalkulator.

Untuk melihat hasil perhitungan sebelumnya, klik tombol `HISTORY`.
